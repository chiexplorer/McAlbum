# McAlbum Ubuntu 单机部署说明

本文说明如何在一台全新的 Ubuntu 24.04 LTS 服务器上部署 McAlbum。生产结构为：

```text
浏览器
  └─ HTTPS / Nginx
       ├─ /              → Nuxt 静态产物
       ├─ /media/        → storage/variants
       └─ /api/          → FastAPI（127.0.0.1:8000）
                              ├─ MySQL（127.0.0.1:3306）
                              └─ storage/ 原图与变体
```

本方案不在生产服务器运行 Nuxt 开发服务。Node.js 只用于检查和生成静态文件；FastAPI 由 systemd 常驻，Nginx 是唯一对公网开放的 Web 服务。

## 1. 部署前准备

需要提前准备：

- 一台 Ubuntu 24.04 LTS 服务器，建议至少 2 核 CPU、2 GiB 内存和足够的图片存储空间；
- 一个拥有 `sudo` 权限的 SSH 用户；
- 一个已经指向服务器公网 IP 的域名，例如 `album.example.com`；
- 可从服务器读取的 Git 仓库地址；
- 当前项目的 `storage/originals` 和 `storage/variants`。真实媒体不在 Git 中，必须单独复制；
- 服务器安全组允许 TCP 22、80、443，禁止向公网开放 3306 和 8000。

除明确标注“本地 Windows PowerShell”外，以下命令均在 Ubuntu 的同一个 SSH 会话中执行。首先修改下面三项，然后整块粘贴：

```bash
export MCALBUM_DOMAIN='album.example.com'
export MCALBUM_REPO_URL='https://example.com/your-account/McAlbum.git'
export MCALBUM_ADMIN_EMAIL='admin@example.com'
```

检查变量，避免把示例域名带入正式配置：

```bash
printf 'DOMAIN=%s\nREPO=%s\nEMAIL=%s\n' "$MCALBUM_DOMAIN" "$MCALBUM_REPO_URL" "$MCALBUM_ADMIN_EMAIL"
```

确认域名已经解析到服务器。返回的地址应包含本机公网 IP：

```bash
getent ahosts "$MCALBUM_DOMAIN"
```

## 2. 安装系统软件

更新系统并安装 Git、Python、Nginx、MySQL 和构建工具：

```bash
sudo apt update && sudo DEBIAN_FRONTEND=noninteractive apt full-upgrade -y
```

如果 `/var/run/reboot-required` 存在，应先执行 `sudo reboot`，重新 SSH 登录后再次执行第 1 节的三个 `export` 命令，再继续安装。

```bash
sudo DEBIAN_FRONTEND=noninteractive apt install -y git curl ca-certificates xz-utils build-essential python3 python3-venv python3-dev nginx mysql-server openssl ufw snapd
```

数据库业务时间由程序保存为 UTC，页面再转为北京时间。服务器本身也建议保持 UTC，方便排查日志：

```bash
sudo timedatectl set-timezone Etc/UTC && timedatectl status
```

启用基础服务：

```bash
sudo systemctl enable --now mysql nginx
```

## 3. 创建服务账号并取得代码

创建无密码的专用服务账号。它不能通过密码远程登录，只负责运行 McAlbum：

```bash
id -u mcalbum >/dev/null 2>&1 || sudo useradd --system --create-home --home-dir /var/lib/mcalbum --shell /bin/bash mcalbum
```

创建代码目录并克隆仓库：

```bash
sudo install -d -o mcalbum -g mcalbum -m 0755 /srv/mcalbum
```

```bash
sudo -u mcalbum git clone -- "$MCALBUM_REPO_URL" /srv/mcalbum
```

如果仓库是私有仓库，应先为服务器配置只读 Deploy Key，再使用 SSH 仓库地址；不要把个人访问令牌写入本文、Git 配置或 shell 脚本。

确认项目关键文件存在：

```bash
test -f /srv/mcalbum/.nvmrc && test -f /srv/mcalbum/apps/api/pyproject.toml && test -f /srv/mcalbum/deploy/nginx/mcalbum.conf.example && echo '项目结构检查通过'
```

## 4. 安装项目指定的 Node.js

项目要求的 Node.js 版本记录在 `.nvmrc`。下面从 Node.js 官方发行目录下载对应二进制包，同时校验 SHA-256。支持 Ubuntu `amd64` 与 `arm64`：

```bash
export NODE_VERSION="$(tr -d '[:space:]' < /srv/mcalbum/.nvmrc)"; case "$(dpkg --print-architecture)" in amd64) export NODE_ARCH='x64' ;; arm64) export NODE_ARCH='arm64' ;; *) echo '仅支持 amd64 或 arm64' >&2; exit 1 ;; esac; printf 'Node.js %s / %s\n' "$NODE_VERSION" "$NODE_ARCH"
```

```bash
cd /tmp && curl -fsSLO "https://nodejs.org/dist/v${NODE_VERSION}/node-v${NODE_VERSION}-linux-${NODE_ARCH}.tar.xz" && curl -fsSLO "https://nodejs.org/dist/v${NODE_VERSION}/SHASUMS256.txt"
```

```bash
cd /tmp && grep " node-v${NODE_VERSION}-linux-${NODE_ARCH}.tar.xz$" SHASUMS256.txt | sha256sum --check --strict
```

```bash
sudo tar -xJf "/tmp/node-v${NODE_VERSION}-linux-${NODE_ARCH}.tar.xz" -C /usr/local --strip-components=1
```

```bash
node --version && npm --version
```

`node --version` 应与 `/srv/mcalbum/.nvmrc` 一致。

## 5. 安装前后端依赖

为 FastAPI 创建独立虚拟环境，并安装运行与检查依赖：

```bash
sudo -u mcalbum python3 -m venv /srv/mcalbum/apps/api/.venv
```

```bash
sudo -u mcalbum /srv/mcalbum/apps/api/.venv/bin/python -m pip install --upgrade pip setuptools wheel
```

```bash
sudo -u mcalbum /srv/mcalbum/apps/api/.venv/bin/python -m pip install -e '/srv/mcalbum/apps/api[dev]' playwright
```

安装前端锁定依赖：

```bash
sudo -u mcalbum -H bash -lc 'cd /srv/mcalbum && npm ci'
```

正式发布检查包含 Playwright。先安装 Chromium 的系统依赖，再以服务账号安装浏览器：

```bash
sudo /srv/mcalbum/apps/api/.venv/bin/python -m playwright install-deps chromium
```

```bash
sudo -u mcalbum -H /srv/mcalbum/apps/api/.venv/bin/python -m playwright install chromium
```

## 6. 准备持久化媒体目录

创建原图、公开变体、临时文件和隔离区。Nginx 只能映射 `variants`，不会公开 `originals`、`temporary` 或 `quarantine`：

```bash
sudo install -d -o mcalbum -g www-data -m 0750 /srv/mcalbum/storage /srv/mcalbum/storage/originals /srv/mcalbum/storage/variants /srv/mcalbum/storage/temporary /srv/mcalbum/storage/quarantine
```

### 6.1 从当前开发机复制已有媒体

在本地 Windows PowerShell 的项目根目录执行：

```powershell
Set-Location D:\Projects\web\McAlbum
```

```powershell
tar -czf .\mcalbum-media.tar.gz -C .\storage originals variants
```

将下面的 SSH 地址改为实际地址后执行：

```powershell
$Server='ubuntu@你的服务器IP'; scp .\mcalbum-media.tar.gz "${Server}:/tmp/mcalbum-media.tar.gz"
```

回到 Ubuntu 服务器解压并校正权限：

```bash
sudo tar -xzf /tmp/mcalbum-media.tar.gz -C /srv/mcalbum/storage && sudo chown -R mcalbum:www-data /srv/mcalbum/storage && sudo find /srv/mcalbum/storage -type d -exec chmod 0750 {} \; && sudo find /srv/mcalbum/storage -type f -exec chmod 0640 {} \; && rm -f /tmp/mcalbum-media.tar.gz
```

确认媒体文件存在：

```bash
sudo -u mcalbum find /srv/mcalbum/storage/originals /srv/mcalbum/storage/variants -type f | head
```

若这是一个没有历史内容的全新站点，可以跳过媒体传输；但当前仓库中的 JSON 内容引用了已有媒体时，不得跳过。

## 7. 初始化 MySQL

生成只包含十六进制字符的随机数据库密码。保持当前 SSH 会话不要关闭，后续命令还会使用该变量：

```bash
export MCALBUM_DB_PASSWORD="$(openssl rand -hex 24)" && test "${#MCALBUM_DB_PASSWORD}" -eq 48 && echo '数据库密码已生成'
```

创建 `utf8mb4` 数据库和仅限本机 TCP 连接的业务账号：

```bash
sudo mysql --execute="CREATE DATABASE IF NOT EXISTS mcalbum CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci; CREATE USER IF NOT EXISTS 'mcalbum'@'127.0.0.1' IDENTIFIED BY '${MCALBUM_DB_PASSWORD}'; ALTER USER 'mcalbum'@'127.0.0.1' IDENTIFIED BY '${MCALBUM_DB_PASSWORD}'; GRANT ALL PRIVILEGES ON mcalbum.* TO 'mcalbum'@'127.0.0.1'; FLUSH PRIVILEGES;"
```

创建 FastAPI 环境文件。这里使用 HTTPS 同源部署，因此生产环境不需要额外跨域：

```bash
sudo install -d -o root -g mcalbum -m 0750 /etc/mcalbum
```

```bash
sudo tee /etc/mcalbum/api.env >/dev/null <<EOF
MCALBUM_DATABASE_URL=mysql+pymysql://mcalbum:${MCALBUM_DB_PASSWORD}@127.0.0.1:3306/mcalbum?charset=utf8mb4
MCALBUM_MEDIA_ROOT=/srv/mcalbum/storage
MCALBUM_CORS_ORIGINS='["https://${MCALBUM_DOMAIN}"]'
MCALBUM_TRUSTED_ORIGINS='["https://${MCALBUM_DOMAIN}"]'
MCALBUM_SESSION_TTL_HOURS=168
MCALBUM_COOKIE_SECURE=true
MCALBUM_ENABLE_BUILD_TRIGGER=false
EOF
```

```bash
sudo chown root:mcalbum /etc/mcalbum/api.env && sudo chmod 0640 /etc/mcalbum/api.env
```

为备份命令创建仅 root 可读的 MySQL 客户端配置：

```bash
sudo tee /etc/mysql/mcalbum-backup.cnf >/dev/null <<EOF
[client]
user=mcalbum
password=${MCALBUM_DB_PASSWORD}
host=127.0.0.1
protocol=tcp
EOF
```

```bash
sudo chmod 0600 /etc/mysql/mcalbum-backup.cnf
```

验证数据库连接和字符集：

```bash
sudo mysql --defaults-extra-file=/etc/mysql/mcalbum-backup.cnf --execute="SELECT VERSION() AS mysql_version, @@character_set_database AS database_charset;" mcalbum
```

## 8. 执行数据库迁移并初始化内容

生产环境禁止由应用启动过程自动建表，必须显式执行 Alembic：

```bash
sudo -u mcalbum -H bash -lc 'set -a; source /etc/mcalbum/api.env; set +a; cd /srv/mcalbum/apps/api && .venv/bin/alembic -c alembic.ini upgrade head'
```

检查迁移头：

```bash
sudo -u mcalbum -H bash -lc 'set -a; source /etc/mcalbum/api.env; set +a; cd /srv/mcalbum/apps/api && .venv/bin/alembic -c alembic.ini current'
```

创建第一个管理员。命令会安全地交互读取两次密码，密码至少 12 位，不会进入 shell 历史：

```bash
sudo -u mcalbum -H bash -lc 'set -a; source /etc/mcalbum/api.env; set +a; cd /srv/mcalbum/apps/api && .venv/bin/python -m app.cli create-admin --username admin --display-name 管理员'
```

将仓库当前的 JSON 媒体、照片和作品集幂等导入 MySQL：

```bash
sudo -u mcalbum -H bash -lc 'set -a; source /etc/mcalbum/api.env; set +a; cd /srv/mcalbum/apps/api && .venv/bin/python -m app.cli import-content --owner admin'
```

如果不希望导入示例/历史 JSON 内容，可以跳过最后一条命令；但此时动态 API 会返回空内容，浏览器刷新后会按空库展示。部署当前已有站点时应执行导入。

## 9. 运行正式发布检查并生成静态站点

正式域名和 API 地址会写入静态构建产物，不能继续使用 `localhost`：

```bash
sudo -u mcalbum -H bash -lc "cd /srv/mcalbum && source apps/api/.venv/bin/activate && export NUXT_PUBLIC_SITE_URL='https://${MCALBUM_DOMAIN}' && export NUXT_PUBLIC_API_BASE='/api' && npm run check:release"
```

该命令依次执行内容发布校验、TypeScript 检查、Vitest、静态生成、静态产物校验、Playwright 和发布清单生成。任何一步失败都应先修复，不要继续上线。

确认产物和发布清单存在：

```bash
test -f /srv/mcalbum/apps/web/.output/public/index.html && test -f /srv/mcalbum/apps/web/.output/release-manifest.json && echo '发布产物检查通过'
```

归档本次发布清单：

```bash
sudo install -d -o root -g root -m 0700 /var/backups/mcalbum/releases && sudo cp /srv/mcalbum/apps/web/.output/release-manifest.json "/var/backups/mcalbum/releases/release-manifest-$(date -u +%Y%m%dT%H%M%SZ).json"
```

## 10. 使用 systemd 运行 FastAPI

创建服务单元：

```bash
sudo tee /etc/systemd/system/mcalbum-api.service >/dev/null <<'EOF'
[Unit]
Description=McAlbum FastAPI
After=network-online.target mysql.service
Wants=network-online.target
Requires=mysql.service

[Service]
Type=simple
User=mcalbum
Group=www-data
WorkingDirectory=/srv/mcalbum/apps/api
EnvironmentFile=/etc/mcalbum/api.env
Environment=PYTHONDONTWRITEBYTECODE=1
ExecStart=/srv/mcalbum/apps/api/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --proxy-headers --forwarded-allow-ips=127.0.0.1
Restart=on-failure
RestartSec=3
TimeoutStopSec=20
UMask=0027
NoNewPrivileges=true
PrivateTmp=true
ProtectHome=true
ProtectSystem=strict
ReadWritePaths=/srv/mcalbum/storage

[Install]
WantedBy=multi-user.target
EOF
```

加载、启动并设置开机启动：

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now mcalbum-api
```

检查状态：

```bash
sudo systemctl --no-pager --full status mcalbum-api
```

从本机访问健康检查：

```bash
curl --fail --silent --show-error http://127.0.0.1:8000/api/health && echo
```

## 11. 配置 Nginx

复制仓库中的生产示例并替换域名：

```bash
sudo cp /srv/mcalbum/deploy/nginx/mcalbum.conf.example /etc/nginx/sites-available/mcalbum
```

```bash
sudo sed -i "s/mcalbum\.example\.com/${MCALBUM_DOMAIN}/g" /etc/nginx/sites-available/mcalbum
```

允许略大于后端 50 MiB 上限的请求体，避免上传图片时由 Nginx 提前返回 413：

```bash
sudo sed -i '/server_name/a\    client_max_body_size 52m;' /etc/nginx/sites-available/mcalbum
```

启用站点并关闭默认站点：

```bash
sudo ln -sfn /etc/nginx/sites-available/mcalbum /etc/nginx/sites-enabled/mcalbum && sudo rm -f /etc/nginx/sites-enabled/default
```

验证配置并平滑重载：

```bash
sudo nginx -t && sudo systemctl reload nginx
```

先通过 HTTP 检查站点和代理：

```bash
curl --fail --silent --show-error "http://${MCALBUM_DOMAIN}/api/health" && echo
```

```bash
curl --fail --silent --show-error --head "http://${MCALBUM_DOMAIN}/"
```

## 12. 配置 HTTPS

使用 Certbot 官方推荐的 Snap 安装方式：

```bash
sudo snap install core && sudo snap refresh core
```

```bash
sudo snap install --classic certbot && sudo ln -sfn /snap/bin/certbot /usr/local/bin/certbot
```

申请证书、自动修改 Nginx 并将 HTTP 重定向到 HTTPS：

```bash
sudo certbot --nginx --redirect --non-interactive --agree-tos --no-eff-email --email "$MCALBUM_ADMIN_EMAIL" -d "$MCALBUM_DOMAIN"
```

测试自动续期：

```bash
sudo certbot renew --dry-run
```

生产登录使用 `Secure` Cookie，只有完成 HTTPS 后才应进行网页登录测试。

## 13. 配置防火墙并完成验收

仅开放 SSH、HTTP 和 HTTPS：

```bash
sudo ufw allow OpenSSH && sudo ufw allow 'Nginx Full' && sudo ufw --force enable
```

```bash
sudo ufw status verbose
```

确认 FastAPI 和 MySQL 只监听本机地址；输出中不得出现 `0.0.0.0:8000` 或公网 `:3306`：

```bash
sudo ss -lntp | grep -E ':(22|80|443|3306|8000)\b'
```

检查公网健康状态、首页、相册页和管理登录页：

```bash
curl --fail --silent --show-error "https://${MCALBUM_DOMAIN}/api/health" && echo
```

```bash
curl --fail --silent --show-error --head "https://${MCALBUM_DOMAIN}/"
```

```bash
curl --fail --silent --show-error --head "https://${MCALBUM_DOMAIN}/album"
```

```bash
curl --fail --silent --show-error --head "https://${MCALBUM_DOMAIN}/manage/login"
```

最后使用浏览器完成以下人工验收：

1. 使用刚创建的 `admin` 登录；
2. 上传一张测试图片并保存草稿；
3. 发布测试照片；
4. 刷新 `/album`，确认无需重启服务即可看到照片；
5. 打开照片详情和图片灯箱；
6. 检查 `/media/` 变体可访问，而原图目录没有公开 URL；
7. 删除或归档专门用于验收的测试内容。

## 14. 日常日志与故障定位

查看 FastAPI 最近 200 行日志：

```bash
sudo journalctl -u mcalbum-api -n 200 --no-pager
```

持续查看 FastAPI 日志：

```bash
sudo journalctl -u mcalbum-api -f
```

查看 Nginx 错误日志：

```bash
sudo tail -n 200 /var/log/nginx/error.log
```

查看 MySQL 状态：

```bash
sudo systemctl --no-pager --full status mysql
```

常见现象：

- `502 Bad Gateway`：先检查 `mcalbum-api` 状态和 `127.0.0.1:8000/api/health`；
- 上传返回 `413`：检查 Nginx 配置中是否存在 `client_max_body_size 52m`；
- 登录后仍提示未登录：确认使用 HTTPS、域名与 `MCALBUM_TRUSTED_ORIGINS` 完全一致，并重新登录；
- 图片返回 `404`：检查 `storage/variants` 是否完整以及 Nginx `alias` 路径；
- 图片返回 `403`：检查 `/srv/mcalbum/storage` 的属主、组和目录执行权限；
- API 返回数据库错误：检查 MySQL、`/etc/mcalbum/api.env` 和 Alembic 当前版本。

## 15. 手工备份

数据库和原图必须一起备份。变体可重建，但建议一并备份以缩短恢复时间。

创建仅 root 可读的备份目录：

```bash
sudo install -d -o root -g root -m 0700 /var/backups/mcalbum
```

执行一次带 UTC 时间戳的数据库、媒体和发布清单备份：

```bash
export BACKUP_STAMP="$(date -u +%Y%m%dT%H%M%SZ)" && sudo sh -c "mysqldump --defaults-extra-file=/etc/mysql/mcalbum-backup.cnf --single-transaction --routines --triggers mcalbum | gzip -9 > '/var/backups/mcalbum/mysql-${BACKUP_STAMP}.sql.gz'" && sudo tar -czf "/var/backups/mcalbum/media-${BACKUP_STAMP}.tar.gz" -C /srv/mcalbum storage/originals storage/variants && sudo cp /srv/mcalbum/apps/web/.output/release-manifest.json "/var/backups/mcalbum/release-manifest-${BACKUP_STAMP}.json" && echo "备份完成：${BACKUP_STAMP}"
```

检查备份：

```bash
sudo ls -lh /var/backups/mcalbum
```

服务器本机备份不能替代异机备份。至少应定期把 `/var/backups/mcalbum` 加密同步到另一台机器或受控备份介质，并实际演练恢复。

## 16. 更新部署

更新前先执行第 15 节备份。然后重新设置本次 SSH 会话需要的变量：

```bash
export MCALBUM_DOMAIN='album.example.com'
```

拉取代码，禁止在服务器上保留手工代码修改：

```bash
sudo -u mcalbum -H bash -lc 'cd /srv/mcalbum && git status --short && git pull --ff-only'
```

更新依赖：

```bash
sudo -u mcalbum /srv/mcalbum/apps/api/.venv/bin/python -m pip install -e '/srv/mcalbum/apps/api[dev]' playwright && sudo -u mcalbum -H bash -lc 'cd /srv/mcalbum && npm ci'
```

重新执行发布检查：

```bash
sudo -u mcalbum -H bash -lc "cd /srv/mcalbum && source apps/api/.venv/bin/activate && export NUXT_PUBLIC_SITE_URL='https://${MCALBUM_DOMAIN}' && export NUXT_PUBLIC_API_BASE='/api' && npm run check:release"
```

显式升级数据库，再重启 API 并重载 Nginx：

```bash
sudo -u mcalbum -H bash -lc 'set -a; source /etc/mcalbum/api.env; set +a; cd /srv/mcalbum/apps/api && .venv/bin/alembic -c alembic.ini upgrade head' && sudo systemctl restart mcalbum-api && sudo nginx -t && sudo systemctl reload nginx
```

归档新的发布清单并复查健康状态：

```bash
sudo cp /srv/mcalbum/apps/web/.output/release-manifest.json "/var/backups/mcalbum/releases/release-manifest-$(date -u +%Y%m%dT%H%M%SZ).json" && curl --fail --silent --show-error "https://${MCALBUM_DOMAIN}/api/health" && echo
```

数据库迁移可能不可逆。不要仅通过切换 Git 版本回滚数据库；出现严重问题时，应停止写入并使用更新前的数据库、媒体和发布清单备份恢复同一快照。

## 17. 恢复要点

恢复操作会覆盖现有数据，应在维护窗口中执行，并先额外保存当前故障现场。基本顺序如下：

1. 停止 `mcalbum-api`，避免恢复期间继续写入；
2. 恢复与同一时间戳对应的 MySQL 备份和媒体备份；
3. 恢复对应代码版本与 `release-manifest`；
4. 检查 Alembic 版本；
5. 启动 API，检查健康状态后再开放写入。

停止 API：

```bash
sudo systemctl stop mcalbum-api
```

在确认目标备份文件后恢复数据库，下面文件名必须替换为实际时间戳：

```bash
sudo sh -c "gunzip -c /var/backups/mcalbum/mysql-YYYYMMDDTHHMMSSZ.sql.gz | mysql --defaults-extra-file=/etc/mysql/mcalbum-backup.cnf mcalbum"
```

媒体恢复涉及覆盖现有目录，不应使用未经核对的通配符。先列出备份并人工确认：

```bash
sudo ls -lh /var/backups/mcalbum/media-*.tar.gz
```

确认后将指定备份解压到 `/srv/mcalbum`，再修复权限：

```bash
sudo tar -xzf /var/backups/mcalbum/media-YYYYMMDDTHHMMSSZ.tar.gz -C /srv/mcalbum && sudo chown -R mcalbum:www-data /srv/mcalbum/storage && sudo find /srv/mcalbum/storage -type d -exec chmod 0750 {} \; && sudo find /srv/mcalbum/storage -type f -exec chmod 0640 {} \;
```

重新启动并检查：

```bash
sudo systemctl start mcalbum-api && curl --fail --silent --show-error http://127.0.0.1:8000/api/health && echo
```
