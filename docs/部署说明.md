# McAlbum Ubuntu 最小部署说明

本文只保留从“安装软件和依赖”到“服务在 Ubuntu 本机正常运行”的主流程。域名解析、HTTPS、云平台端口映射、防火墙、备份、升级和恢复不在本文展开。

本文最终得到的是可供本机和受控网络验收的 HTTP 服务。没有配置 HTTPS 前，不要通过公网提交真实管理员密码或上传敏感内容。

部署采用社区常见的单机组合：

```text
APT 管理系统软件
NVM 管理 Node.js
Python venv + pip 管理 FastAPI 依赖
MySQL 保存业务数据
Alembic 管理数据库结构
systemd 常驻运行 FastAPI
Nginx 提供静态前端、公开图片并代理 API
```

## 工作项总览

1. **设置部署变量**：把当前目录记录为项目根目录，并填写站点公开地址。
2. **安装系统软件**：通过 Ubuntu APT 安装 Git、Python、MySQL、Nginx 等基础组件。
3. **安装 Node.js**：通过 NVM 读取项目 `.nvmrc`，安装项目指定版本。
4. **安装项目依赖**：Python 使用独立虚拟环境，前端使用 `npm ci` 按锁文件安装。
5. **准备媒体目录**：创建原图、公开变体、临时文件和隔离目录。
6. **初始化 MySQL**：创建数据库、业务账号和 FastAPI 环境文件。
7. **初始化应用数据**：用 Alembic 建表并创建第一个管理员。
8. **生成静态前端**：生成 Nuxt 静态产物和发布清单。
9. **运行 FastAPI**：通过 systemd 启动并保持后端常驻。
10. **运行 Nginx**：提供网页和图片，并把 `/api/` 转发给 FastAPI。
11. **本机验收**：确认服务、端口、API 和首页都能正常响应。

完成第 11 项后，McAlbum 已在服务器本机正常运行。之后只需根据云服务商规则，把公网端口映射到 Nginx 的内部 `80` 端口。不要把 FastAPI 的 `8000` 或 MySQL 的 `3306` 映射到公网。

## 0. 前提

- 系统为 Ubuntu 24.04 LTS；
- 当前使用 `root` 账号，并已进入 McAlbum 项目根目录；
- 项目路径不包含空格；
- 正式提交已经在开发机或 CI 运行过 `npm run check:release`；
- 本文按“重新通过网页上传媒体”的方式部署，不复制旧服务器的 `storage` 内容，也不导入示例内容。

下面所有命令均为单行命令，可逐条复制执行。

## 1. 设置部署变量

填写服务器对外访问时实际使用的地址。NAT 环境需要包含公网端口，例如 `http://album.example.com:18080`；暂时没有域名时也可以填写公网 IP 和端口。

```bash
export PROJECT_ROOT="$(pwd -P)" MCALBUM_SERVER_NAME='album.example.com' MCALBUM_PUBLIC_ORIGIN='http://album.example.com:18080' MCALBUM_COOKIE_SECURE='false'
```

没有域名时，将 `MCALBUM_SERVER_NAME` 填为公网 IP；它不包含协议和端口。

如果已经配置 HTTPS，将 `MCALBUM_PUBLIC_ORIGIN` 改为实际的 `https://...` 地址，并把 `MCALBUM_COOKIE_SECURE` 改为 `true`。

确认当前目录确实是项目根目录：

```bash
test -f "$PROJECT_ROOT/.nvmrc" && test -f "$PROJECT_ROOT/package.json" && test -f "$PROJECT_ROOT/apps/api/pyproject.toml" && echo '项目目录检查通过'
```

重新登录 SSH 后，需要重新进入项目根目录并再次执行本节的 `export` 命令。

## 2. 安装系统软件

使用 Ubuntu 官方软件源安装运行和构建所需组件：

```bash
apt update && DEBIAN_FRONTEND=noninteractive apt install -y git curl ca-certificates build-essential python3 python3-venv python3-dev nginx mysql-server openssl acl
```

启用 MySQL 和 Nginx：

```bash
systemctl enable --now mysql nginx
```

成功标志：

```bash
systemctl is-active mysql nginx
```

应连续输出两个 `active`。

## 3. 使用 NVM 安装 Node.js

安装 NVM：

```bash
PROFILE=/dev/null bash -c 'curl -fL --retry 5 --retry-delay 3 --retry-all-errors https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash'
```

加载 NVM，并按照 `.nvmrc` 安装 Node.js：

```bash
export NVM_DIR="$HOME/.nvm" && source "$NVM_DIR/nvm.sh" && cd "$PROJECT_ROOT" && nvm install && nvm alias default "$(cat .nvmrc)" && nvm use --silent && node --version && npm --version
```

成功标志：`node --version` 与项目 `.nvmrc` 中的版本一致。

## 4. 安装项目依赖

创建 Python 虚拟环境并安装 FastAPI 及开发检查依赖：

```bash
python3 -m venv "$PROJECT_ROOT/apps/api/.venv" && "$PROJECT_ROOT/apps/api/.venv/bin/python" -m pip install --upgrade pip setuptools wheel && "$PROJECT_ROOT/apps/api/.venv/bin/python" -m pip install -e "$PROJECT_ROOT/apps/api[dev]"
```

按照 `package-lock.json` 安装前端依赖：

```bash
export NVM_DIR="$HOME/.nvm" && source "$NVM_DIR/nvm.sh" && cd "$PROJECT_ROOT" && nvm use --silent && npm ci
```

服务器只负责构建和运行，不需要安装 Playwright Chromium。完整的 `npm run check:release` 应在开发机或 CI 完成。

## 5. 准备媒体目录

创建媒体存储目录：

```bash
install -d -o root -g www-data -m 0750 "$PROJECT_ROOT/storage" "$PROJECT_ROOT/storage/originals" "$PROJECT_ROOT/storage/variants" "$PROJECT_ROOT/storage/temporary" "$PROJECT_ROOT/storage/quarantine"
```

目录用途：

- `originals`：上传原图；
- `variants`：网页公开使用的图片变体；
- `temporary`：上传和处理过程中的临时文件；
- `quarantine`：校验失败或需要隔离的文件。

## 6. 初始化 MySQL 和应用配置

生成随机数据库密码：

```bash
export MCALBUM_DB_PASSWORD="$(openssl rand -hex 24)" && test "${#MCALBUM_DB_PASSWORD}" -eq 48 && echo '数据库密码已生成'
```

创建数据库和仅限本机连接的业务账号：

```bash
mysql --execute="CREATE DATABASE IF NOT EXISTS mcalbum CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci; CREATE USER IF NOT EXISTS 'mcalbum'@'127.0.0.1' IDENTIFIED BY '${MCALBUM_DB_PASSWORD}'; ALTER USER 'mcalbum'@'127.0.0.1' IDENTIFIED BY '${MCALBUM_DB_PASSWORD}'; GRANT ALL PRIVILEGES ON mcalbum.* TO 'mcalbum'@'127.0.0.1'; FLUSH PRIVILEGES;"
```

创建 FastAPI 环境文件：

```bash
install -d -o root -g root -m 0700 /etc/mcalbum && printf '%s\n' "MCALBUM_DATABASE_URL=mysql+pymysql://mcalbum:${MCALBUM_DB_PASSWORD}@127.0.0.1:3306/mcalbum?charset=utf8mb4" "MCALBUM_MEDIA_ROOT=${PROJECT_ROOT}/storage" "MCALBUM_CORS_ORIGINS='[\"${MCALBUM_PUBLIC_ORIGIN}\"]'" "MCALBUM_TRUSTED_ORIGINS='[\"${MCALBUM_PUBLIC_ORIGIN}\"]'" 'MCALBUM_SESSION_TTL_HOURS=168' 'MCALBUM_REGISTRATION_RATE_WINDOW_SECONDS=3600' 'MCALBUM_MEDIA_UPLOAD_LIMIT_USER=20' 'MCALBUM_MEDIA_UPLOAD_LIMIT_ADMIN=100' "MCALBUM_COOKIE_SECURE=${MCALBUM_COOKIE_SECURE}" 'MCALBUM_ENABLE_BUILD_TRIGGER=false' > /etc/mcalbum/api.env && chmod 0600 /etc/mcalbum/api.env
```

验证数据库可连接：

```bash
set -a && source /etc/mcalbum/api.env && set +a && "$PROJECT_ROOT/apps/api/.venv/bin/python" -c "from sqlalchemy import create_engine, text; import os; engine=create_engine(os.environ['MCALBUM_DATABASE_URL']); print(engine.connect().execute(text('SELECT VERSION()')).scalar())"
```

成功标志：输出 MySQL 版本号。

## 7. 初始化数据库并创建管理员

使用 Alembic 将数据库升级到当前版本：

```bash
set -a && source /etc/mcalbum/api.env && set +a && cd "$PROJECT_ROOT/apps/api" && .venv/bin/alembic -c alembic.ini upgrade head && .venv/bin/alembic -c alembic.ini current
```

创建第一个管理员，命令会交互读取两次密码：

```bash
set -a && source /etc/mcalbum/api.env && set +a && cd "$PROJECT_ROOT/apps/api" && .venv/bin/python -m app.cli create-admin --username admin --display-name 管理员
```

本文按空白站点部署，因此不执行 `import-content`。服务上线后直接通过网页上传照片和创建内容。

## 8. 生成静态前端

使用真实公开地址生成 Nuxt 静态站点，并生成发布清单。部分旧仓库快照会把用于保留空目录的 `media/.gitkeep` 复制到公开产物中；它不是媒体文件，因此在静态校验前显式删除：

```bash
export NVM_DIR="$HOME/.nvm" && source "$NVM_DIR/nvm.sh" && cd "$PROJECT_ROOT" && nvm use --silent && source apps/api/.venv/bin/activate && export NUXT_PUBLIC_SITE_URL="$MCALBUM_PUBLIC_ORIGIN" NUXT_PUBLIC_API_BASE='/api' && npm run generate:web && rm -f "$PROJECT_ROOT/apps/web/.output/public/media/.gitkeep" && npm run validate:static && python scripts/validate_static_output.py --release && npm run snapshot:release
```

成功标志：

```bash
test -f "$PROJECT_ROOT/apps/web/.output/public/index.html" && test -f "$PROJECT_ROOT/apps/web/.output/release-manifest.json" && echo '静态前端生成成功'
```

## 9. 使用 systemd 运行 FastAPI

创建 systemd 服务。systemd 负责开机启动、异常重启和日志收集：

以下配置沿用当前“root 执行、项目位于当前目录”的部署约定，因此 FastAPI 也以 root 运行。systemd 与 Nginx 的职责划分是主流单机方案；若以后提高安全隔离，再把运行用户迁移为专用服务账号。

```bash
printf '%s\n' '[Unit]' 'Description=McAlbum FastAPI' 'After=network-online.target mysql.service' 'Wants=network-online.target' 'Requires=mysql.service' '' '[Service]' 'Type=simple' 'User=root' 'Group=www-data' "WorkingDirectory=${PROJECT_ROOT}/apps/api" 'EnvironmentFile=/etc/mcalbum/api.env' 'Environment=PYTHONDONTWRITEBYTECODE=1' "ExecStart=${PROJECT_ROOT}/apps/api/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --proxy-headers --forwarded-allow-ips=127.0.0.1" 'Restart=on-failure' 'RestartSec=3' 'TimeoutStopSec=20' 'UMask=0027' 'NoNewPrivileges=true' 'PrivateTmp=true' 'ProtectSystem=strict' "ReadWritePaths=${PROJECT_ROOT}/storage" '' '[Install]' 'WantedBy=multi-user.target' > /etc/systemd/system/mcalbum-api.service
```

加载并启动服务：

```bash
systemctl daemon-reload && systemctl enable --now mcalbum-api
```

检查 FastAPI：

```bash
systemctl is-active mcalbum-api && curl --fail --silent --show-error http://127.0.0.1:8000/api/health && echo
```

成功标志：服务状态为 `active`，并返回健康检查 JSON。

## 10. 使用 Nginx 提供网站

复用仓库中的 Nginx 模板，并替换站点名称与项目根目录；模板会分别映射公开图片变体和可下载原图：

```bash
cp "$PROJECT_ROOT/deploy/nginx/mcalbum.conf.example" /etc/nginx/sites-available/mcalbum && sed -i -E "s|/srv/mcalbum|${PROJECT_ROOT}|g; s|mcalbum\.example\.com|${MCALBUM_SERVER_NAME}|g" /etc/nginx/sites-available/mcalbum && sed -i '/server_name/a\    client_max_body_size 52m;' /etc/nginx/sites-available/mcalbum
```

项目位于 `/root` 时，为 Nginx 的 `www-data` 用户授予静态页面、公开变体和可下载原图的读取权限：

```bash
setfacl -m u:www-data:x /root && setfacl -m u:www-data:x "$PROJECT_ROOT" && setfacl -R -m u:www-data:rX "$PROJECT_ROOT/apps/web/.output/public" "$PROJECT_ROOT/storage/variants" "$PROJECT_ROOT/storage/originals" && setfacl -R -d -m u:www-data:rX "$PROJECT_ROOT/storage/variants" "$PROJECT_ROOT/storage/originals"
```

启用站点并重载 Nginx：

```bash
ln -sfn /etc/nginx/sites-available/mcalbum /etc/nginx/sites-enabled/mcalbum && rm -f /etc/nginx/sites-enabled/default && nginx -t && systemctl reload nginx
```

## 11. 本机验收

检查三个服务：

```bash
systemctl is-active mysql mcalbum-api nginx
```

应连续输出三个 `active`。

检查监听端口：

```bash
ss -lntp | grep -E ':(80|8000|3306)\b'
```

FastAPI 的 `8000` 和 MySQL 的 `3306` 应只监听本机地址，不应直接暴露到公网。

通过 Nginx 检查 API：

```bash
curl --fail --silent --show-error -H "Host: ${MCALBUM_SERVER_NAME}" http://127.0.0.1/api/health && echo
```

检查首页：

```bash
curl --fail --silent --show-error --head -H "Host: ${MCALBUM_SERVER_NAME}" http://127.0.0.1/
```

看到 API 健康 JSON 和首页 `200 OK`，表示从依赖安装到服务运行的主流程已经完成。

## 11. 清理缺少媒体文件的内容

迁移数据库但没有同步全部 `storage` 文件时，数据库可能仍保留照片元数据，页面只能显示替代文字。先执行只读扫描；该命令不会修改任何记录：

```bash
cd "$PROJECT_ROOT/apps/api" && set -a && source /etc/mcalbum/api.env && set +a && .venv/bin/python -m app.cli cleanup-missing-media
```

确认报告中的照片和作品集确实不需要保留后，以管理员账号名写入审计日志并应用清理：

```bash
cd "$PROJECT_ROOT/apps/api" && set -a && source /etc/mcalbum/api.env && set +a && .venv/bin/python -m app.cli cleanup-missing-media --apply --actor admin
```

该操作不会硬删除数据库记录或现存文件：缺失媒体会标记为 `failed`，相关照片和作品集进入 `deleted`，失效玩家头像会解绑；同时清理不再公开的静态 JSON。动态页面刷新后立即生效。最后重新执行第 8 节的静态前端生成命令，使首屏兜底快照也同步更新。

## 最小故障入口

FastAPI 启动失败：

```bash
journalctl -u mcalbum-api -n 100 --no-pager
```

Nginx 配置失败：

```bash
nginx -t && tail -n 100 /var/log/nginx/error.log
```

MySQL 启动失败：

```bash
systemctl --no-pager --full status mysql
```
