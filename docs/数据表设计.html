LAYER 02 / TABLE LEDGER

表级设计

字段类型和可空性来自实际 MySQL 结构；“应用默认值”与业务枚举来自当前 SQLAlchemy/Pydantic 实现。数据库没有配置的服务端默认值不会被误写为数据库默认值。

没有匹配的表或字段，请换一个关键词。
时间与时区

业务时间写入 MySQL DATETIME 时统一保存为无时区 UTC；API 或页面读取后再转换为 Asia/Shanghai。仅日期语义使用 DATE。

ID 稳定性

业务实体使用字符串 ID，发布后不随显示名称变化；自增整数只用于不暴露给用户的权限行和媒体变体行。

JSON 使用边界

stories.sections、邀请码权限和审计元数据使用 JSON；照片标签已经规范化为 tags 与 photo_tags，实体关系通过普通列、外键和关联表表达。

媒体存储边界

数据库只保存相对 storage_key 与尺寸、哈希等元数据，图片二进制保留在本地持久化文件系统，不进入 MySQL BLOB。

删除策略

会话、细分权限、媒体变体、评论及内容关联随父记录级联清理；其他历史归属默认受外键约束保护，账号与玩家解绑采用 SET NULL。

状态由服务层守护

状态列当前是 VARCHAR，合法转换由 FastAPI Service 与 Pydantic 校验，并非 MySQL ENUM 或 CHECK 约束。
